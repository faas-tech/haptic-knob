# Changelog

Every change bumps `metadata.version` in SKILL.md and adds an entry here.

## 1.0.1 - 2026-09-19

Published as a personal global skill. Same identifier rules as the ECM
repository copy. Description and method now work outside that repo: they no
longer require `ecm-voice` on a relative path. Prose vocabulary still lives
in ecm-voice or ecm-ai-language when those skills are present.

## 1.0.0 - 2026-09-13

Split from ecm-ai-language 1.0.0. Carries the code, file and variable
conventions, the four-stage naming table, the date-kind rule, the avoid list
and the refactor discipline. Prose vocabulary moved to ecm-voice so a brief
never loads naming rules.
